# Workflow: apple-design

Activa la skill `apple-design`.

1. Revisa el componente o pantalla solicitada a través de las 5 lentes de diseño:
   - **Lente 1:** Accesibilidad y áreas táctiles mínimas (44px móvil / 28px desktop).
   - **Lente 2:** Jerarquía y ritmo de espaciados (grid de 8pt).
   - **Lente 3:** Materiales translúcidos y cristal esmerilado (frosted glass).
   - **Lente 4:** Micro-interacciones y físicas elásticas al hacer clic.
   - **Lente 5:** Eliminación de clichés visuales genéricos de IA.
2. Presenta propuestas concretas con código CSS/Tailwind para elevar la calidad estética.
