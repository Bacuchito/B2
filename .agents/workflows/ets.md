# Workflow: ets

Activa la skill `espanol-tecnico`.

1. Toma el texto, prompt o fragmento técnico solicitado.
2. Aplica las directrices de Español Técnico Simplificado:
   - Elimina la pasiva refleja y rodeos; usa modo imperativo directo.
   - Divide instrucciones compuestas (una sola acción por frase).
   - Sustituye palabras ambiguas ("adecuado", "correcto", "etc.") por valores exactos.
   - Explica de forma clara y accesible cualquier término técnico complejo.
3. Devuelve la versión limpia, concisa y sin ambigüedad.
